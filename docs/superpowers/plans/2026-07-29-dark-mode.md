# Dark Mode Implementation Plan

> **Goal:** Transform portfolio from light to dark mode with 6 Brandcast-inspired effects. 2 files touched.

**Architecture:** CSS-first via Tailwind v4 `@theme` tokens in `index.css` + className replacements in `App.tsx`. No new deps, no structural changes.

**Tech Stack:** React 19, Tailwind CSS v4, GSAP, Lenis

## Global Constraints

- Pure black base: `#000`
- Accent: `#BEF500` lime (unchanged)
- Cards use glass morphism: `bg-white/[0.03] backdrop-blur-sm border-white/[0.06]`
- No copy changes, no HTML restructuring, no new dependencies
- All existing GSAP animations must work (enhanced, not broken)
